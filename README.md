# RatO - Rating Ontology for Films

RatO is an OWL ontology project to provide a semantic description of basic film information, personnel, awards and rating mechanisms.

The project includes a static website, ontology files, Widoco-generated documentation with a WebVOWL visualization.

## Features

- Models movie ratings from data sources such as IMDb and Rotten Tomatoes.
- Represents rating scores, rating scales, voters, awards, genres, personnel and languages through OWL classes and properties.
- Provides ontology serializations in N-Triples file.
- Includes a HTML specification documentation and interactive WebVOWL graph.
